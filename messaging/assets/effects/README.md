# Effect overlays

An animated WebP with transparency named for an effect (`confetti.webp`, `balloons.webp`, `fireworks.webp`,
`hearts.webp`, `snow.webp`, `lasers.webp`, `ghosts.webp`) plays over the conversation in place of the effect the app
draws itself (lib/effects.dart). The list, the sizes and a prompt for each are in docs/effects.md.
