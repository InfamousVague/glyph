Discord servers

Link a Discord server, see who is in its voice channels, and talk in them from Ghost.

Link a Discord server and its voice channels show in Ghost as a group of spaces, with who's in each. Press one and you're in that Discord channel from Ghost: Ghost's bot joins it and carries the sound and the chat both ways, so people in Discord hear you and you hear them.

Link a server

You need someone who can manage the Discord server for the first step. After that, anyone with the code can link it in their app.

  1. New › Add a Discord server

  2. Add the bot to the server

    Tap Add the bot to your server. Discord opens: pick the server and authorise it. Skip this if the bot is already there.

  3. Get a code in Discord

    In any channel of the server, type /ghost link. The bot answers with a six-character code only you see. It works once, for 10 minutes.

  4. Enter it

    Back in Ghost, type the code and tap Link the server.

Talk in a Discord voice channel

The server shows as a group in Messages, its voice and stage channels as spaces, with who's in each. Press one to join: Ghost's bot joins that channel for you, and you talk to the people there.

  • People in Discord see the bot speak as Ghost · your name.
  • Messages in the space go to the channel's chat in Discord, and theirs come back.
  • People in Discord are marked as such in the call; their volume and mute work as anyone's.

The bot's commands

In DiscordDoes
/ghost linkGives a one-time code to link the server in Ghost.
/ghost statusSays how many Ghost Messaging links the server has.
/ghost unlinkTakes every link away. The server's group in Ghost says so.
What the bot can see

The bot sees what any member of a voice channel sees: who is in it, and the sound and chat of the channel it's bridging while someone from Ghost is in it. The link is a token kept on your device only.
