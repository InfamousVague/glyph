Notes and tickets as files. Boards, Gantts and queries as text.

Ghost.md keeps everything as .md files in a folder you own: journals, boards, canvases, a team's tickets. Obsidian opens them, GitHub renders them, git backs them up. Claude reads and writes them, in the app or through a connector.

Marks

A few plain marks, drawn as tools.

The file stays text. Any Markdown app opens it; Obsidian Tasks and GitHub read the same marks.

  • To-dos with details

    A person, a priority and a due day on any to-do, drawn as chips you tap.

    - [ ] Renew the insurance @matt ⏫ 📅 2026-10-02

  • Tickets

    Front matter says it is a ticket. Its fields become a panel; a notebook with a key numbers them.

    ---
type: ticket
id: PRD-11
status: In progress
---

  • Queries

    What matches across every note, as a table, list, board, calendar, Gantt, chart or count.

    ```query
from: tickets [[Product]]
where: status != Done
show: gantt
```

  • Boards

    Named items in columns. Drag a card to move it.

    ```board
To do: ship-page
Done: pick-date
```

  • Rules

    Sentences, run as the notebook's tickets change.

    ```rules
When status becomes Done,
post to Slack #launches.
```

  • Sums, diagrams, embeds

    A line starting = shows its answer. A mermaid fence is drawn. A YouTube link alone is a card.

    = $45 + $18 * 2   → $81

For teams

Tickets, cycles and a Gantt, in files the team owns.

  1. Tickets in notebooks

    Keys like HT-12, statuses, assignees, due days, priorities, labels, components, sub-tickets with a progress bar, templates.

  2. Boards, tables, calendars, charts, rollups

    One query fence, shown any way. Pick a few cards and change them all at once.

  3. Cycles, epics, roadmap

    Burndown and velocity, unfinished work carried over, epics that add up their tickets.

  4. My tickets and Triage

    Everything assigned to you, by when it's due. Triage by keys: J/K move, A assign, P priority, T done.

  5. Forms that land as tickets

    Share a link; each answer arrives sealed and becomes a ticket in the notebook.

  6. Pull requests, timers, watchers, history, digest, duplicates

    A GitHub PR on its ticket; Start/Stop; a morning digest; Merge into… with one Undo.

Claude

Built in, and connected.

In the app with your own Anthropic key, kept in the device's secure storage. Or from claude.ai, Claude Desktop and Claude Code through the connector, which reads, searches and writes notes, tickets and comments, and shows as online while it works.

https://ghostmarkdown.com/api/mcp
# Claude Code
claude mcp add --transport http glyph https://ghostmarkdown.com/api/mcp
# claude.ai, Claude Desktop
Settings › Connectors › Add custom connector

Your files

Plain Markdown, all the way down.

One folder. Every note a .md file named after its title; versions beside it, kept like git; attachments under Library/. Back it up to any git host with the plugin, or publish it as a site.

Library/
├── .glyph/            config.json: folders, settings
├── .trash/
├── image/ file/ video/ recordings/
├── Inbox/
└── workspaces/
    └── Product/
        ├── Meetings/
        ├── Launch plan.md
        ├── Launch plan.versions   v1..v3, who and when
        ├── Product.md              the notebook: key, statuses, rules
        └── PRD-11 Login loop.md
  1. Every version, kept like git

    A line saying who and when, then the lines out (-) and in (+). Every fiftieth is a whole copy.

  2. Sealed before it syncs

    Encrypted on the device, end to end. No account needed at all.

  3. Take it all with you

    One .ghostex export, or the folder itself: it already is the export.
