Ten versions of ghostmarkdown.com

At ghostmarkdown.com/1/ to /10/. The same app and the same words, laid out ten ways, from a page with almost nothing on it to one with everything on it. Each borrows from a site worth borrowing from: Notion, Discord, GitHub, Linear, Vercel, Raycast, Apple. The boxes say how much is on the page.

Density: 1 is a sentence a screen, 5 is a spec sheetEvery download and address is the real oneLight, dark and the named themes follow your pick on the home page
  1. 01

    AirAfter Notion

    One centred column, a big sentence, a big picture, and nothing crowding either. The quietest version.

    Density
  2. 02

    BlocksAfter Discord

    Full-width bands in colour, display type you can read from across the room, pictures zig-zagging down the page.

    Density
  3. 03

    TerminalAfter GitHub and git

    Dark, code first: a terminal in the hero, the file tree, a grid of features with the lines that draw them.

    Density
  4. 04

    BentoAfter Vercel and Stripe

    A short hero, then everything in one grid of cards of different sizes, each a feature with its picture.

    Density
  5. 05

    ReadmeAfter a README on GitHub

    The site as a document: a table of contents down the side, headings, tables of what works where, code blocks. The densest version.

    Density
  6. 06

    PaletteAfter Raycast

    The hero is a command palette: type to find a feature, press a row to read about it. Keyboard shortcuts everywhere.

    Density
  7. 07

    ShellAfter a product tour

    The whole page lives inside an app window: a sidebar of sections on the left, the section on the right, as if you were already in Ghost.

    Density
  8. 08

    SlidesAfter Apple and Arc

    One feature per screen, snapping as you scroll, a dot for each down the side. The least on any screen.

    Density
  9. 09

    FeedAfter Linear's changelog

    The page is the app's real changelog, newest first, with the downloads and the connector pinned beside it.

    Density
  10. 10

    SpecsAfter a tech-specs page

    Definition lists and a platform matrix: every feature on one line, every platform in one column, no pictures at all.

    Density
