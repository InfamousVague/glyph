# Keys and the command palette

Everything Ghost.md can do is one search away in the command palette. This chapter covers the palette, the keyboard shortcuts on a computer, and the shortcuts a phone has: the launcher, the side key and the Fold.

## The command palette

The palette is a list of everything you can do right now, with a search field: "What would you like to do?". Type a few letters and press Return, or tap the row.

To open it:

- **On a Mac**, press `⌘K`. On a keyboard without Command, `Ctrl+K`.
- **On a phone**, tap **Search and commands**, the magnifier on the dock, or the search tool in the sidebar.

Press Escape, or use your phone's back gesture, to close it. The note behind it stays where it was.

### What's in it

What it offers depends on where you are. Over a note, that note's commands come first:

| Over a note | |
|---|---|
| **Talk into this note** | Record into it. On a journal, **Speak an entry**. |
| **Show it formatted** / **Show the marks** | Switch how the note is shown. |
| **Fix spelling**, **Make a list**, **Continue** | Ask the AI to work on the note. |
| **Fill the blanks** | When the note has blanks to fill. |
| **Links to this note**, **Local graph of this note** | What links here. |
| **Pin it to the top**, **Archive this note**, **Delete this note** | |
| **File it in …**, **Take it out of its workspace** | Move it between workspaces. |
| **Close the … tab**, **Put this tab in a new group** | Tabs and their groups. |

Then the rest of the app:

| Anywhere | |
|---|---|
| **New note**, **New notebook**, **New journal**, **New entry in …** | Make something. |
| **Speak a new note** | Start recording. |
| **Home**, **All notes**, **Trash**, **Tags**, **Graph of your notes** | Go somewhere. |
| **Today's note** | Open or make today's daily note. |
| **Ask Claude** | With the Claude plugin added. |
| **Show …** | A smart notebook, or one workspace's notes; **Show all notes** clears it. |
| **Go to …**, **Close …**, **Back**, **Forward** | Your open tabs. |
| **Open …** | Any note, by its title. |
| **Theme: …** | Switch theme. |
| **Settings**, **Market**, **Notifications**, **Organizations** | |
| **Cheat sheet**, **Ghost.md Academy**, **The welcome walkthrough** | Help. |

Search matches more than the names. `dark` finds the themes, `plugins` finds the Market, `bin` finds Trash. Rows that have a shortcut show it on the right.

Simple mode keeps the palette, with fewer rows. See [[Simple and Advanced]].

## Shortcuts on a Mac

| Keys | What it does |
|---|---|
| `⌘K` | The command palette. |
| `⌘N` | A new note. |
| `⇧⌘D` | Today's note. |
| `⌘F` | Find in the open note, or search Settings while it is open. |
| `⌘,` | Settings. |
| `⌘R` | Sync now. |

The same commands are in the Mac's menu bar. On a desktop without a Command key, Control takes its place.

### In the editor

The editor has the keys you'd expect from a text editor:

| Keys | What it does |
|---|---|
| `⌘Z` / `⇧⌘Z` | Undo / redo. |
| `⌘A` | Select all. |
| `⌘]` / `⌘[` | Indent / outdent. |
| `⌘/` | Comment out the line. |
| `⌥⌘↑` / `⌥⌘↓` | Add a cursor above / below. |
| `⌘Return` | A blank line below, from anywhere in the line. |
| `⌥←` / `⌥→` | Move a word at a time. |

**`/` on an empty line**, with a hardware keyboard, opens the list of things to add at the caret, the same list as the **+** beside an empty line. Keep typing to filter it, then press Return. The `/` itself isn't written.

In a list, a board's card or the + list, the arrow keys move, Return chooses and Escape closes.

## On an Android phone

### Launcher shortcuts

Long-press Ghost.md's icon for its shortcuts: **New note**, **Voice note**, **Today**, **Search** and **Scan**. Drag one to your home screen to keep it there.

### The side key

You can make Ghost.md your phone's assistant, so that holding the side key talks to Claude, even from the lock screen.

1. Add the Claude plugin, and keep an Anthropic API key in **Settings › Claude**.
2. Under **Phone assistant**, switch on **Ghost.md as the phone's assistant**. Android's screen opens: pick Ghost.md under **Default digital assistant app**. Ghost.md can't choose itself; Android asks you to.
3. Point the side key at the assistant in your phone's settings. On a Samsung: Settings › Advanced features › Side button › Press and hold › Digital assistant. On a Pixel: Settings › System › Gestures › Press and hold power button › Digital assistant.

Then hold the side key, or use your phone's assistant gesture, and Ghost.md listens, shows Claude thinking, and opens the note Claude writes in. Without an API key on the phone, it records a voice note instead.

The microphone is only open while you talk. Ghost.md never listens out for a word. To go back to your phone's own assistant, pick it again in the same place.

## On a folding phone

On a folding phone such as a Galaxy Z Fold, the note **unfolds with the phone**: as you open it, the page is paper folded down its middle, flattening as the hinge opens. Your hand drives it. It runs only on the way open; closing never folds it back up, and a phone left half open settles the note flat by itself. With reduced motion there is no unfold.

Opened out, Ghost.md uses the room. Settings shows its list and a page side by side, the Market's cards stand two to four across, and a plugin's page opens beside them.

## On the iPhone

The iPhone app has the palette on **Search and commands**. It doesn't record, so there is no side key or voice shortcut.
