# Release notes

The "What's new" box on the release page (Release › Production or Testing › Create new release › Release notes).
Play allows 500 characters per language. The language tag stays as the Console writes it: `<en-GB>` … `</en-GB>`.

## 1.9.0, the first release on Google Play

```
<en-GB>
The first release on Google Play.

Speak a note and watch it take shape as Markdown, cue by cue. Say Hey Ghost to put words into a note by name. After a recording, the AI on the phone listens again and marks what it would change. Meetings record with the screen off and are written up afterwards, with a summary under the title. Notes are plain .md files, synced end to end encrypted if you sign in, and never read by anyone else.
</en-GB>
```

About 450 characters. If the build has no Meeting, drop the sentence that starts "Meetings record".
